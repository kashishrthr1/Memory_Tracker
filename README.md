# Memory Tracker
DejaLearn is a full-stack MERN application designed to help users track learning topics and schedule revisions based on the "Spaced Repetition" (Forgetting Curve) methodology.

🚀 Live Demo: https://memory-tracker-ui.onrender.com

✨ Features
Smart Revision Scheduling: Automatically calculates the next revision date using a spaced repetition algorithm.

User Authentication: Secure Login and Signup system using JWT (JSON Web Tokens).

Topic Management: Create, update, and track study topics with ease.

Progress Dashboard: A clean overview of completed topics and upcoming revisions.

Responsive Design: Fully optimized for mobile, tablet, and desktop views using Tailwind CSS.
